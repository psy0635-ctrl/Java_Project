# GitHub 프로젝트 품질 점검 시스템

## 프로젝트 소개

**GitHub 프로젝트 품질 점검 시스템**은 Java 객체지향 프로그래밍 개념을 활용하여 만든 콘솔 프로그램입니다.

사용자가 GitHub 프로젝트 정보(커밋 수, README 여부, 배포 여부, 기술스택 개수, 설명 길이 등)를 입력하면, 프로젝트 유형별 기준으로 **품질 점수(100점 만점)**와 **등급**, **맞춤형 개선 조언**을 계산하여 콘솔에 출력합니다.

---

## 주요 기능

1. **프로젝트 유형별 차등 점수 계산** - 웹, AI, Java 프로젝트마다 항목별 가중치가 다름
2. **100점 만점 품질 점수 산출** - 5개 항목(README, 배포, 커밋 수, 기술스택, 설명 길이) 평가
3. **A+ ~ D 등급 판정** - 점수 구간에 따른 자동 등급 부여
4. **맞춤형 개선 조언 제공** - 부족한 항목에 대한 구체적인 개선 방향 안내
5. **보고서 형식 결과 출력** - 프로젝트 정보, 점수, 등급, 조언을 보기 좋게 출력

## 사용 기술 및 적용 OOP 개념

### 사용 기술

| 사용 기술 | 설명 |
|---|---|
| Java | 프로그램 전체 구현 |
| Scanner | 사용자 입력 처리 |
| 순수 Java | 외부 라이브러리 없이 표준 라이브러리만 사용 |

### 적용된 객체지향(OOP) 개념

| OOP 개념 | 적용 위치 | 설명 |
|---|---|---|
| 클래스 | 전체 8개 클래스 | 역할별로 클래스를 분리하여 구현 |
| 생성자 | Project, 자식 클래스들, ProjectManager | 객체 생성 시 필드 초기화, 자식은 super() 호출 |
| 상속 (extends) | WebProject, AIProject, JavaProject | Project 추상 클래스를 상속받아 기능 확장 |
| 오버라이딩 (@Override) | calculateQualityScore(), getProjectType() | 유형별로 다른 점수 계산 방식과 이름 반환 |
| 접근제한자 | 필드(private), 메서드(public/private) | 외부 접근 제어로 데이터 보호 |
| 다형성 | ProjectManager, PortfolioReport | 부모 타입(Project) 변수로 자식 객체 처리 |
| 캡슐화 | Project 클래스 필드 + getter | private 필드를 getter로만 접근 |
| 추상화 | Project (abstract class, abstract method) | 공통 틀을 정의하고 구체적 구현은 자식에게 위임 |

## 클래스 구조 (8개)

| 번호 | 클래스명 | 역할 |
|:---:|---|---|
| 1 | Main | 프로그램 시작점. ProjectManager를 생성하고 실행 |
| 2 | Project | 부모 추상 클래스. 공통 필드, getter, 추상 메서드 정의 |
| 3 | WebProject | Project 상속. 배포 여부에 높은 가중치를 둔 점수 계산 |
| 4 | AIProject | Project 상속. 기술스택과 설명에 높은 가중치를 둔 점수 계산 |
| 5 | JavaProject | Project 상속. 커밋 수와 설명에 높은 가중치를 둔 점수 계산 |
| 6 | QualityAnalyzer | 점수를 등급(A+~D)으로 변환하고 종합 평가 제공 |
| 7 | PortfolioReport | 프로젝트 정보 + 점수 + 등급 + 조언을 보고서 형식으로 출력 |
| 8 | ProjectManager | 메뉴, 입력, 객체 생성, 전체 실행 흐름 관리 |

### 유형별 가중치 (합계 100점)

| 평가 항목 | WebProject | AIProject | JavaProject |
|---|:---:|:---:|:---:|
| README 여부 | 20 | 20 | 20 |
| 배포 여부 | 30 | 10 | 15 |
| 커밋 수 | 15 | 20 | 25 |
| 기술스택 개수 | 20 | 25 | 15 |
| 설명 길이 | 15 | 25 | 25 |

## 실행 방법

1. IntelliJ IDEA에서 이 프로젝트를 연다.
2. `src/Java_Project2/Main.java` 파일을 연다.
3. `main()` 메서드 옆의 ▶ 버튼을 클릭하거나, 우클릭 → "Run 'Main.main()'"을 선택한다.
4. 콘솔에서 메뉴에 따라 프로젝트 정보를 입력하면 결과가 출력된다.
