# SafeTrade

## 프로젝트 소개

SafeTrade는 Java를 활용한 **중고거래 사기 위험도 체크 프로그램**입니다.

사용자가 중고거래 전에 몇 가지 질문에 답하면, 프로그램이 위험 점수를 계산하고 거래 위험 등급을 알려줍니다.

---

## 주제 선정 이유

최근 중고거래를 이용하는 사람들이 많아지면서 사기 피해도 발생하고 있습니다.

특히 다음과 같은 상황은 사기 위험이 높을 수 있습니다.

- 시세보다 너무 저렴한 가격
- 판매자의 직거래 거부
- 선입금 요구
- 부족한 판매자 정보
- 급하게 거래를 유도하는 행동

그래서 거래 전에 간단히 위험 요소를 확인할 수 있는 프로그램을 만들었습니다.

---

## 사용 기술

| 사용 기술 | 설명 |
|---|---|
| Java | 프로그램 구현 |
| Scanner | 사용자 입력 처리 |
| switch문 | 거래 물품 종류 선택 |
| for문 | 질문 반복 출력 |
| if문 | 답변에 따른 점수 계산 |
| 배열 | 질문과 점수 저장 |

---

## 주요 기능

1. 거래 물품 종류 선택
2. 물품 종류에 따른 주의사항 출력
3. 사기 위험 질문 5개 응답
4. 위험 점수 계산
5. 위험 등급 출력

---

## 위험 점수 기준

| 점수 | 위험 등급 |
|---:|---|
| 0 ~ 20점 | 안전 |
| 21 ~ 50점 | 주의 |
| 51 ~ 80점 | 위험 |
| 81점 이상 | 매우 위험 |

---

## 실행 예시

```text
===== SafeTrade 중고거래 사기 위험도 체크 프로그램 =====

[거래 물품 종류를 선택하세요]
1. 전자기기
2. 의류
3. 티켓
4. 게임 / 취미용품
5. 기타

선택 번호 입력: 1

전자기기 거래를 선택했습니다.
전자기기는 고가 거래가 많아 선입금 사기를 주의해야 합니다.

1. 시세보다 가격이 너무 저렴한가요?
1. 예
2. 아니오
입력: 1

위험 점수 +20점

```

## 느낀 점

이번 프로젝트를 통해 Java의 기본 문법인 `Scanner`, `if문`, `switch문`, `for문`, `배열`을 실제 프로그램에 적용해볼 수 있었습니다.

단순한 계산 프로그램이 아니라 실생활에서 사용할 수 있는 **중고거래 사기 위험도 체크 프로그램**을 만들면서 조건문과 반복문의 활용 방법을 더 잘 이해할 수 있었습니다.
